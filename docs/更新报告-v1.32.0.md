# v1.32.0 更新报告（2026-10-21 上线 · 两台机器都已升完）

这份写的是**这次改了什么**（不是怎么用，怎么用另有一页：`docs/使用说明-逐格优化-v1.32.0.md`）。

## 0. 一句话

把「票面是怎么印的」和「我们要怎么发给公司系统」这两件事在核对区摊开成两行给你看，中间加了一颗**由你决定**的「优化」按钮；同时改了统计口径：**你点优化接受的写法不再算成"你纠正了模型"**。

## 1. 做了什么

### 1.1 新加一份「国别写法表」（`polish.py`）

以前"哪个国家的邮编要带横杠、哪个国家的州用两字母码"这些规矩散在提交代码和老同事的经验里，界面看不见。现在集中成一份表，**按钮、红旗、提交口径三处共用同一份**，不会出现"界面说能改、发出去是另一版"。

表里的实际条数：

| 内容 | 条数 |
|---|---|
| 邮编形状（国别） | **13 国**：BR CA CZ GB GR IE JP NL PL PT SE SK US（其中 CA GB IE NL 的邮编本来就含字母，只比形状、不强改） |
| 州／省官方码 | **4 国共 104 个码**：US 56、BR 27、CA 13、AU 8 |
| 可点「优化」的规则 | **分单 9 类**（邮编补形 / 州名换码 / 识别号去标点 / 清不可见字符 / 国家转两字母码 / 电话取号 / 传真取号 / 识别号拼格 / 识别号从别处提回）；**主单 7 类**（国家那格只转大写，不替它转两字母码——那格收不收要等 IT 定） |
| 覆盖的格子 | 每个主体 8 列（邮编 / 州省 / 国家 / 电话 / 传真 / 识别号 / AEO / 邮箱）；分单两家、主单三家 |

### 1.2 核对区改成"一份值给两行"

上面一行是**票面原样**，下面一行是**真正要发给公司系统的写法**。两行一样时只占一行，不多占地方。分单、主单两侧都做了。

### 1.3 逐格「优化」按钮 + 待办条上「可优化 N 格」

- 两行不一样时那一格才出现按钮，旁边一句话写明为什么这么改、改成什么；
- **点下去才改**，不点就照原来的发；改完可以点「还原」回去；
- 待办条上「可优化 N 格」，点一颗少一颗；
- **明确不做整票一键**：一次改几十格，人就再也不看原值了，而这个方案的全部价值就在"先来一眼"。

### 1.4 三类只挂红旗、绝不改值

| 红旗 | 为什么不改 |
|---|---|
| 邮编位数与那个国家对不上 | 可能是票面本身就少印，软件猜不出该补几位 |
| HS 编码不足 6 位 | 补零就是替票面编数字 |
| 国家那一格认不出 | 要靠人看票，软件不猜 |

### 1.5 留痕（谁改的、按哪条规则改的）

点优化走的是**原来那条人工改值的链**（暂存逐列 diff → 提交重算红旗 → 台账记改了几列），没有新流程、没有新按钮去公司。只在事件里多带一样东西：**这一格当时是按哪条规则换的**。规则号**只挂在真被改动的列上**——你按了优化但那格最后没变，就不记。

### 1.6 统计口径改了（这一条对录入同事最相关）

以前只要值变了就算"人修正了模型"。现在：**带规则号的那些格子，既不算人修正，也不留在准确率的分母里，单独报一档。**

- 看板多一张卡：**「按规则优化 N 列」**（第七张）；
- 口径条多一句：**「这一档既不算人修正、也不进分母」**；
- 导出 Excel：口径表里逐规则摊成「POSTAL 1 列」这种人读得的话，「每张票」多一栏列出是哪几列；
- 判据是**最后一次动过这一列的事件**：先点了优化、之后你自己又敲过一次那一格 → 那就算你改的，不再免记；暂存之后到真正发出去之间又改的，同样算人的动作。

### 1.7 界面「更新说明」加了这一版五条（管理员进页自动弹一次）

## 2. 没动什么（同样要说清）

- **软件不会自动改任何值**；不改发货人/收货人整串、公司名、地址、城市（照抄口径与"收货人城市留全称"两条定案）；
- 不做的事：HS 补零、韩国邮编补横杠（新旧两制并存推不出来）、德国邦与意大利大区缩写（没有两字母码）、剥邮编前的国别前缀（`SE-` 是内容不是格式）；
- **列面没变**：分单还是 38 列、主单还是 36 列；**提交口径没变**；**红旗硬门没变**（还有未确认红旗照样挡提交）；**分单解析的提示词一个字没动**（提示词只管照抄票面，写法归一是这一层做的）；
- 老票不需要任何迁移动作，历史统计数不会因为这次改口径而变。

## 3. 这是按谁的话做的

- 2026-10-20 业主：「只挂旗可以，但再增加一个优化按钮，把原有的值优化成规则填写的值，就是人先来一眼原值正确，然后再点优化按钮」；界面形态选了**「并列两行、票面值在上」**；「主单同步做吧，把能做的规则全部加上」。
- 2026-10-21 业主：「按你建议改」——带规则号的不算人工修正，另记一档。

## 5. 一件现场事实（免得被当成"没上线"）

线上现有 60 张票里，**可由规则改的格子是 0 张**——这批票的邮编/州名/识别号本来就没得推。所以同事打开老票看不到那颗按钮是**正常的**，不是功能没上。会见到按钮的是这几类：识别号那格空着而号印在地址行或页底 customs 区、同一主体两个号要拼进一格、邮编缺横杠、州名是全写。另外**已经发出去的票一律不给按钮**（待办条会写「可优化 0 格」）。
