# 逐格「优化」怎么用（v1.32.0 · 2026-10-21 上线）

给录入/制单的同事。看完这一页就知道多出来的那行字和多出来的那颗按钮是什么、什么时候该点、什么时候不该点。

## 一、界面上多了什么

核对区每一格现在可能给两行：

- **「票面：xxxx」** —— 原件上印的样子（模型抄出来的那版）
- **下面一行** —— 真正会发给公司系统的写法

两行一样时只占一行，什么都不多显示，**这是正常的**。

两行不一样时，那一格右边多一颗 **「优化」** 按钮，旁边一句话说明为什么要这么改。最上面待办条也多一颗 **「可优化 N 格」**。

## 二、怎么用（三步）

1. **先看「票面」那一行**，对着原件确认：这确实是票面印的，不是模型抄错。
2. 抄对了 → **点「优化」**，这一格换成规则写法，「可优化 N 格」少一格。
3. 点错了 → 点那一格的 **「还原」**，回到票面那一版。

**只有你按下去才改。** 系统不会自己动你的票，也**没有**「整票一键全改」——一次改几十格，人就再也不看原值了，这功能的全部意义就是"你先看一眼"。

## 三、这几种情况"没有按钮"是对的，不是坏了

| 情况 | 为什么没有 |
|---|---|
| 两行本来就一样 | 没的可改 |
| 这张票已经发出去了 | 交出去的票一颗都不给按，「可优化」永远写 0（公司那边也要挡） |
| 正确写法推不出来 | 只挂红旗、要你看着票定，见第四节 |
| 这一格你自己已经改过了 | 以你手改的为准，不再给你按钮 |

## 四、只挂红旗、**绝不改值**的三类

| 红旗说的是什么 | 你要做什么 |
|---|---|
| 邮编位数与那个国家对不上 | 照票面核一遍：是票面本来就少印/多印，还是抄漏了。**别自己补零凑位数** |
| HS 编码不足 6 位 | 票面印几位就是几位，不许补零；真是票面缺的就按缺的处理 |
| 国家那一格认不出 | 按票面原样填，不要翻译、不要换成两字母码 |

## 五、点「优化」实际在接受哪些写法（举例）

- **巴西邮编（CEP）8 位要带横杠**：`04546040` → `04546-040`
- **波兰邮编 5 位**：`00123` → `00-001`
- **美国州名用两字母官方码**：`CALIFORNIA` → `CA`（注意：巴西、德国的州没有两字母码，这种绝不动）
- **识别号那一格空着，号其实印在地址行或页底 customs 区** → 把号提进这一格
- **同一主体有两个号**（海关号 + 本土税号）→ 用 ` / ` 拼在同一格，一个都不许丢，例如 `IT03268900267 / 911201117706402073`
- 识别号里混进的标签词（VAT/CNPJ/USCI）和多余标点会被清掉

推不出唯一写法的，一律只做旗、不给你按钮。

## 六、统计里那一档：**按「优化」不算你纠正了模型**

「解析正确率」窗口多了一张卡 **「按规则优化 N 列」**，口径条也写了一句说明。规则是：

- 你点「优化」接受的那些写法，**不算人工修正模型**，也**不占准确率的分母**，单独报个数；
- 你**手工敲进去**改的，照旧算你的修正；
- 如果先点了优化、之后你自己又改过一次那一格，那还是算你改的。

所以按这颗按钮不会让你手上的票"变好看"也不会"变难看"——它记的是"接受了一条写法规定"，不是"发现模型读错"。

## 七、什么也没看到的时候

先按 **Ctrl+F5** 硬刷一次，然后核对两件事：

- 顶栏版本号应是 **1.32.0**
- 待办条上应有 **「可优化 N 格」** 这几个字（哪怕 N 是 0）

如果连"可优化"这三个字都没有，说明浏览器里还是旧页面，报回来。
